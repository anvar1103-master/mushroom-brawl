# Brawl Green

Браузерная 3D-игра: командные бои грибов и жуков на маленьких аренах, вид от третьего лица.
Сделана для Яндекс Игр, идёт на ПК и телефонах, язык — русский или английский (выбирается сам).

## Что уже есть (этап 1)

- Арена «Грибная поляна»: кусты-изгороди, камни и пни, высокая трава для засад, грибница в центре. Карта симметричная.
- Три героя со своими атаками и супер-ударами:
  - **Шляпник** (мухомор) — дробовик веером; супер — широкий залп, отбрасывает врагов;
  - **Бабах** (жук-бомбардир) — бомбы навесом через стены, взрыв оставляет горящую лужу; супер — пять бомб дорожкой;
  - **Жалка** (оса) — дальний выстрел жалом, чем дальше цель, тем больнее; супер — луч сквозь стены.
- Три заряда атаки, которые восстанавливаются сами. Шкала супера копится от попаданий.
- Режим **«Споры»** 3 на 3 с ботами: собери 10 спор и удержи их 15 секунд.
- Пять героев: Шляпник (дробовик), Бабах (бомбы), Жалка (снайпер), Катыш (рикошеты), Стрекот (автоматчик).
- Время суток (день, закат, ночь) и сезоны (лето, осень, зима) меняются от матча к матчу, или их можно выбрать в настройках.
- Режим **«Дождевикбол»** 3 на 3: футбол грибом-дождевиком, 2 гола — победа, при ничьей золотой гол.
- Режим **«Последний гриб»** (королевская битва): 10 бойцов, каждый сам за себя, лабиринт из кустов, сжимающийся ядовитый туман, ящики с кристаллами силы.
- Вид из-за плеча героя, прицел в центре экрана. Кусты-изгороди выше героев: за ними можно прятаться.
- Сквозь стены враг виден силуэтом только вблизи (до 10 м). Враг, по которому попала твоя команда, подсвечивается для всех на 3,5 секунды.
- В высокой траве героя не видно, пока враг не подойдёт близко.
- ПК: WASD — бег, мышь — камера и прицел, ЛКМ — атака, ПКМ или E — супер. Телефон: джойстик слева, правая половина экрана — поворот камеры, кнопка атаки (короткое нажатие — автоприцел, с протяжкой — поворот камеры и выстрел в прицел), кнопка супера.

## Как запустить у себя

Нужен Node.js.

```
npm install
npm run serve          # открыть http://localhost:8123/src/index.html
```

Сборка архивов (`packages/brawl-green-web.zip` и `packages/brawl-green-yandex.zip`, `index.html` в корне):

```
npm run build
```

## Как устроен код

| Файл | Что внутри |
|---|---|
| `src/js/maps.js` | карты текстом (половина карты, вторая получается поворотом) |
| `src/js/arena.js` | постройка арены, столкновения, поиск пути |
| `src/js/heroes.js` | параметры героев и их модели |
| `src/js/rig.js`, `src/js/anim.js` | сборка моделей со «скелетом» и процедурные анимации |
| `src/js/combat.js` | движение, атаки, снаряды, урон, супер, видимость в траве |
| `src/js/mode.js` | режим «Споры» |
| `src/js/env.js` | время суток и сезоны: небо, свет, снег, листопад, светлячки |
| `src/js/football.js` | режим «Дождевикбол»: мяч, ворота, голы |
| `src/js/royale.js` | режим «Последний гриб»: туман, кристаллы силы, места |
| `src/js/bots.js` | боты |
| `src/js/player.js` | управление и камера |
| `src/js/hud.js` | интерфейс боя и меню |
| `src/js/yandex.js` | Яндекс Игры: SDK, реклама, пауза |

Ассеты собираются скриптами `tools/fetch-assets.py` и `tools/build-assets.mjs`. Откуда они — в `CREDITS.md`.
