# Brawl Green — памятка для Claude

Браузерная 3D-игра (three.js) для Яндекс Игр. Лесной сеттинг, вид из-за плеча, кусты-стены, боты. Владелец говорит по-русски: отвечай просто и по-русски, без жаргона. Всё в игре оригинальное: никаких имён, героев, графики и звуков из Brawl Stars. Ассеты только CC0 (Quaternius, Kenney, OpenGameArt), без внешних запросов в сборке.

## Как работать
- Работаем этапами. Рабочая ветка — `claude/dreamy-euler-4ve6df`. Перед этапом: `git fetch origin main && git checkout -B claude/dreamy-euler-4ve6df origin/main`.
- Конец этапа: `npm run build` → `node tools/test.mjs --dist` → commit → push → PR в `main` → merge (владелец заранее разрешил вливать самому). Каждый этап отдельным PR, чтобы его можно было откатить (Revert). Метка до больших обновлений: тег `v1.2-before-royale-ai`.
- Ссылка для игры: https://anvar1103-master.github.io/mushroom-brawl/ (GitHub Pages из папки `docs/`, её заполняет `npm run build`, `docs/` и `packages/*.zip` коммитятся).
- Проверяй сам, не на словах: бот-матчи, скриншоты на ПК и телефоне (маленькие 667×375, 740×360 и вертикальный 390×844), потом отчёт.
- Не создавай лишних файлов в `tools/`: временные скрипты называй `tools/_что-то.mjs` и удаляй после запуска (stop-хук ругается на неотслеживаемые файлы).

## Команды
- Локальный сервер: `setsid nohup npx http-server -p 8124 -c-1 -s . &` из корня репозитория, страница `http://localhost:8124/src/index.html?lang=ru`. Он гаснет между ходами, перезапускай.
- Тест: `node tools/test.mjs` (исходники) или `--dist` (сборка). Играет бот-матчи за всех героев в обоих режимах, футбол, обе карты «Споры», проверяет английский и отсутствие внешних запросов. Раз упала одна проверка, а повтор прошёл — это случайность бот-матчей.
- Сборка: `npm run build` (esbuild → `dist/web`, `dist/yandex`, `docs/`, `packages/*.zip`).
- Скриншоты и замеры: playwright в headless Chromium (`--use-gl=angle --use-angle=swiftshader`), поэтому первый кадр после смены карты рисуется ~20 с — это софтверный рендер, на настоящем железе не так.
- Тестовые крючки в игре: `window.__bg` (`start({mode,hero,map,skipCount})`, `autopilot`, `sim(сек)`, `tick`, `cam([x,y,z,tx,ty,tz])`, `env(небо,сезон)`, `pause`, `bench`, `G`, `A`, `CAM`, `s`).

## Помощники (.claude/agents)
- `balance-tester` — тесты и бот-матчи для баланса (`tools/test.mjs`, `tools/balance.mjs`), короткий вердикт. Звать после изменений героев, оружия, ботов, режимов.
- `phone-ui-checker` — экраны на трёх размерах телефона (`tools/ui-check.mjs`) + просмотр скриншотов. Звать после изменений меню, HUD, кнопок.
- `asset-scout` — поиск и загрузка CC0-ассетов (Kenney, Quaternius, OpenGameArt) с лицензиями.
Их длинный вывод остаётся у них, в основную сессию приходит итог — так дешевле.

## Устройство (src/js)
- `main.js` — запуск, меню, настройки, поток матча, события→HUD, главный цикл, `__bg`. `state.js` — общий `G`, `emit/on`.
- `engine.js` — рендерер, уровни графики (`LEVEL` low/medium/high, `stdMat`), запечённое небо, `setSky`, адаптация `perfWatch`. `env.js` — время суток и сезоны, снег/листья/светлячки.
- `arena.js` — тайловая карта (TILE 1.6), коллизии, `segHit`, поиск пути, построение арены, ящики, `seasonize`. `maps.js` — карты: `glade`, `creek` («Споры»), `maze` (лабиринт 35×35), `pitch` (футбол).
- `combat.js` — бойцы, видимость (трава, кусты, «пятнание» попаданием), атаки (fan, needle, lob, barrage, beam, bounce, burst), снаряды, урон. `shotfx.js` — светящиеся снаряды, вспышки, подпалины.
- `heroes.js` — характеристики и модели 5 героев: shroom (дробовик), beetle (бомбы), wasp (снайпер, прицел), roly (Катыш, рикошет), hopper (Стрекот, очереди). `anim.js`, `rig.js` — процедурные скелеты и анимации.
- Режимы: `mode.js` («Споры» 3×3), `royale.js` («Последний гриб» 10 бойцов, туман, ящики с силой), `football.js` («Дождевикбол» 3×3). `bots.js` — мозги ботов под все режимы. `player.js` — управление, камера, прицел, `hud.js` — интерфейс.
- `i18n.js` + `en.js` — русский исходный, английский через словарь фраз: любой новый русский текст добавляй в `en.js`, иначе тест «английский без русского» упадёт.

## Подводные камни (уже наступали)
- Шейдеры без NaN: не `smoothstep` с равными/обратными краями, `pow` с обрезанным основанием.
- Новые материалы с общей `onBeforeCompile` цепляй через `seasonize`/`windify`, не затирай чужие.
- Наружный пол арены лежит на y=-0.85, иначе закрывает воду.
- Конфликты имён CSS-классов (кнопка `tscope` против оверлея `scope`) — проверяй на телефоне.
- На телефоне всё должно помещаться и нажиматься: джойстик ловит касания только на поле боя, панели прокручиваются.
- Любое изменение боёвки проверяй баланс-прогоном (боты, 25 матчей «Последнего гриба»): средние места героев сейчас 4,6–6,3 из 10.
